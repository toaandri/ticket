# Security reporting

Do not post credentials, personal data, QR tokens or an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting on this repository if enabled; otherwise contact the repository owner through a private channel you already have and request a secure reporting route. No dedicated security email or response SLA is configured by this project.

Provide the affected revision, minimal synthetic reproduction, impact and proposed mitigation. Preserve financial/audit records and avoid tests against real payments or other tenants. See `docs/security/README.md` for the current threat model and known upstream mobile advisories. This demo has no production certification.
